# Menu artwork and supplied sticker

`fishguy-sticker.png` is the user's supplied image, copied unchanged. It is third-party/user-provided branding and is not relicensed by the MWC MIT license.

`menu-halftone.png` is a deterministic halftone of the actual original Combat Master LobbyBG2 texture, with that sticker composited. The original game artwork remains its owners' content. The canvas and scene composition are preserved. `menu-halftone.provenance.json` records the source and output hashes; `installer/tools/menu_artwork.py` records the exact reproducible filter. The earlier AI-redrawn experiment was rejected and is superseded.
